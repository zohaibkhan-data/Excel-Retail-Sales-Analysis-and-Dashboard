# Retail Sales Analysis & Executive Dashboard (Microsoft Excel)

## Project Overview
An end-to-end Microsoft Excel data analysis project evaluating retail sales performance, order metrics, and regional revenue across Pakistan.

## Key Business Metrics
- **Total Sales:** $4,378,030.00
- **Total Cost:** $4,265,400.00
- **Total Profit:** $112,630.00
- **Total Transactions:** 100 Orders (30 Online, 38 Store)
- **Average Order Value:** $43,780.30

## Excel Skills Demonstrated
- **Dynamic Formulas:** `SUMIF`, `COUNTIF`, `AVERAGE`, `MIN`, `MAX`, and `COUNTA` for automated KPI reporting.
- **Interactive Dashboard:** Pivot Tables, Pivot Charts, and Slicers for regional and category filtering.
